Circular user image or initials, with an optional conic progress ring (great for showing daily-goal completion around the profile photo).

```jsx
<Avatar name="Aiko Tanaka" />
<Avatar src="/me.jpg" size="lg" ring ringPercent={80} />
```

Props: `src`, `name` (initials fallback), `size` (sm/md/lg/xl), `ring`, `ringPercent`.
