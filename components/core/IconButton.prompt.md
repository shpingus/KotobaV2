Compact icon-only button for nav, close, audio replay, and toolbar actions. Circular by default. Always pass `label` for accessibility.

```jsx
<IconButton label="Replay audio" variant="brand"><i data-lucide="volume-2" /></IconButton>
<IconButton label="Close" variant="ghost"><i data-lucide="x" /></IconButton>
<IconButton label="Settings" square><i data-lucide="settings" /></IconButton>
```

Variants: `neutral` / `brand` / `accent` / `ghost`. Sizes: `sm` (36) / `md` (44) / `lg` (52). Pass `square` for rounded-square.
