Small status or count pill. Soft-filled by default; pass `solid` for a high-emphasis fill.

```jsx
<Badge tone="success">Mastered</Badge>
<Badge tone="accent" dot>New</Badge>
<Badge tone="brand" solid size="sm">N5</Badge>
```

Tones: `brand` / `accent` / `success` / `warning` / `danger` / `neutral`. Sizes `sm` / `md` / `lg`. Props: `solid`, `dot`.
