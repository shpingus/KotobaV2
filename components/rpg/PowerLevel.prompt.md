The aggregate "word power" (言力) medallion — a gold 力 medal plus one number summing the four skill stats. Used to gate boss challenges.

```jsx
<PowerLevel value={47} />
<PowerLevel value={47} size="lg" label="Word power" />
<PowerLevel value={12} size="sm" showLabel={false} />
```

Props: `value`, `size` (sm/md/lg), `label`, `showLabel`.
