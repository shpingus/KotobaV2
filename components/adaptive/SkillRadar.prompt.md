A 4-axis radar of the learner's skills — the dent shows the weakness; the weakest axis is automatically marked in torii red.

```jsx
<SkillRadar size={200} stats={[
  { label: 'Vocabulary', jp: '語彙', value: 62 },
  { label: 'Grammar',    jp: '文法', value: 48 },
  { label: 'Listening',  jp: '聴解', value: 31 },
  { label: 'Reading',    jp: '読解', value: 55 },
]} />
```

Props: `stats` (label/jp/value), `max`, `size`, `color`.
